In the digital age, data is gold. But copying and pasting data from websites is a waste of time. Web scraping allows you to automate this process. We'll use BeautifulSoup to extract information from an HTML page.

1. The Legal & Ethical Note

Always check a website's robots.txt file before scraping. Don't spam the server with thousands of requests per second, and never scrape private data without permission.

2. Installation

pip install requests beautifulsoup4

3. Simple News Scraper

This script fetches a webpage and prints out all the headlines found in <h2> tags.

import requests
from bs4 import BeautifulSoup

url = "https://example-news-site.com"
response = requests.get(url)

if response.status_code == 200:
    soup = BeautifulSoup(response.text, 'html.parser')
    headlines = soup.find_all('h2')

    for i, h in enumerate(headlines):
        print(f"{i+1}: {h.get_text(strip=True)}")
else:
    print("Failed to retrieve the page")

4. Next Steps

Webサイトにある大量のデータ（価格情報、ニュース、商品リストなど）を自動で集める技術、それが「Webスクレイピング」です。今回はPythonの定番ライブラリ BeautifulSoup を使った基本を紹介します。

1. マナーとルール（超重要）

スクレイピングは強力ですが、ルールを守らないとサイトに負荷をかけたり、法的なトラブルになる可能性があります。

  • サーバーに負荷をかけない（time.sleep()で間隔をあける）。
  • 利用規約で禁止されていないか確認する。
  • 個人情報の無断収集はしない。

2. 必要な準備

pip install requests beautifulsoup4

3. ニュースの見出しを取得するスクリプト

以下のコードは、特定のサイトから <h2> タグで囲まれた見出しをすべて抜き出す例です。

import requests
from bs4 import BeautifulSoup
import time

url = "https://example.com/news" # 収集したいURL
res = requests.get(url)

# ページが正常に開けたか確認
if res.status_code == 200:
    soup = BeautifulSoup(res.text, 'html.parser')
    # h2タグをすべて探す
    headlines = soup.find_all('h2')

    for i, h in enumerate(headlines):
        print(f"見出し{i+1}: {h.get_text().strip()}")
        # 1秒待機（サーバーへの優しさ）
        time.sleep(1)
else:
    print("アクセスに失敗しました")

4. 取得したデータの活用

取得したデータを pandas ライブラリと組み合わせてExcel（CSV）に保存すれば、立派な市場調査レポートの完成です。

さらに学ぶには： 最近の動的なサイト（JavaScriptで中身が変わるサイト）の場合は、Selenium や Playwright というツールを使う必要があります。
