Stage 1: Introduction Python is the world's most popular language for automation. Whether you want to automate spreadsheets, scrape websites, or manage files, Python is your best friend. In this guide, we will set up your environment properly to avoid common pitfalls.
Stage 2: Setup ### Installing Python (The Right Way) Go to [python.org](https://python.org) and download the latest version. **Important:** During installation on Windows, make sure to check the box that says **"Add Python to PATH"**. ### Your First Script Create a file named `hello.py` and type the following: 
import os

def main():
    print("Python Automation Lab: Active")
    print(f"Current Directory: {os.getcwd()}")

if __name__ == "__main__":
    main()
Stage 3: Pro Tips Always use virtual environments (`venv`) to keep your projects clean and avoid version conflicts.

ステップ 1：準備 「Pythonを始めてみたけど、最初の1歩で動かない...」そんな経験をしたくない人のための、超・親切ガイドです。 まず公式サイト [python.org](https://python.org) から最新版をダウンロードします。 !!! warning "【最重要】絶対に忘れてはいけないチェック" インストーラーを起動した直後の画面一番下に、**「Add Python to PATH」**というチェックボックスがあります。**これをチェックしないと、この後の手順が全てエラーになります。**
ステップ 2：実装 ### おすすめの「道具箱」：VS Code メモ帳でプログラムを書いてはいけません。プロも使う **Visual Studio Code (VS Code)** を使いましょう。 * [VS Code公式サイト](https://code.visualstudio.com/)からインストール。 ### 最初のプログラムを動かす `test.py` という名前でファイルを作成してください。 
msg = "Pythonの自動化、最高！"
print(msg)
1. ターミナルを開きます。 2. `cd` コマンドでフォルダへ移動します。 3. `python test.py` と入力して実行！
ステップ 3：レベルアップ ### 初心者が絶対にはまる「ミスの要因」集 * **全角スペースの混入:** コードの途中に全角スペースが入っていると動かなくなります。 * **ファイル名のミス:** `test.py.txt` のように、後ろに `.txt` が隠れていませんか？
