What is Python?

Python is a high-level, interpreted programming language known for its readability and versatility. It is used in web development, data science, automation, and more.

Fun Fact: Python was named after "Monty Python's Flying Circus", not the snake!

How to Setup Python

  1. Go to python.org
  2. Download the latest version for your OS.
  3. Run the installer and make sure to check "Add Python to PATH".
If you forget to check "Add to PATH", you might have trouble running Python from the command line.

Your First Script

Create a file named hello.py and type:

print("Hello, Python World!")

Run it with: python hello.py

Congratulations! You've just run your first Python script.

Pythonとは？

Python（パイソン）は、読みやすさと汎用性の高さで知られるプログラミング言語です。ウェブ開発、データサイエンス、AI、業務効率化の自動化など、幅広く使われています。

豆知識: Pythonの名前の由来は、ヘビではなくイギリスのコメディ番組「空飛ぶモンティ・パイソン」です。

Pythonのセットアップ方法

  1. 公式サイト python.org にアクセスします。
  2. OSに合わせた最新バージョンをダウンロードします。
  3. インストーラーを実行し、必ず「Add Python to PATH」にチェックを入れてください。
「Add to PATH」にチェックを忘れると、コマンドプロンプトやターミナルでPythonが動かない原因になります。

最初のスクリプトを動かす

hello.py というファイルを作り、以下の1行を書き込みます。

print("こんにちは、Pythonの世界へ！")

実行するには、ターミナルで python hello.py と入力します。

おめでとうございます！これでPythonの第一歩を踏み出しました。
