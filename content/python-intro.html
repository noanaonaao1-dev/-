Python is the world's most popular language for automation. Whether you want to automate spreadsheets, scrape websites, or manage files, Python is your best friend. In this guide, we will set up your environment properly to avoid common pitfalls.

1. Why Python for Automation?

Python's syntax is close to English, making it easy to read and write. More importantly, it has a massive library ecosystem (PyPI) that allows you to do almost anything with just a few lines of code.

2. Installing Python (The Right Way)

Go to python.org and download the latest version. Important: During installation on Windows, make sure to check the box that says "Add Python to PATH". If you miss this, your terminal won't recognize Python commands.

3. Your First Script

Create a file named hello.py and type the following:

import os

def main():
    print("Python Automation Lab: Active")
    print(f"Current Directory: {os.getcwd()}")

if __name__ == "__main__":
    main()

4. Managing Libraries with pip

To automate things, you'll need external tools. Use pip to install them:

pip install requests pandas openpyxl
Pro Tip: Always use virtual environments (venv) to keep your projects clean and avoid version conflicts.

「Pythonを始めてみたけど、最初の1歩で動かない...」そんな経験をしたくない人のための、超・親切ガイドです。

1. Pythonのインストール（最大の難所）

まず公式サイト python.org から最新版をダウンロードします。

【最重要】絶対に忘れてはいけないチェック
インストーラーを起動した直後の画面一番下に、「Add Python to PATH」というチェックボックスがあります。これをチェックしないと、この後の手順が全てエラーになります。
もし忘れてインストールしてしまった場合は、一度アンインストールしてやり直すのが一番確実で早いです。

2. おすすめの「道具箱」：VS Code

メモ帳でプログラムを書いてはいけません。プロも使う Visual Studio Code (VS Code) を使いましょう。

  • VS Code公式サイトからインストール。
  • 左側のアイコンから「Python」と検索し、Microsoft製の拡張機能をインストール。

3. 最初のプログラムを動かす

パソコンのデスクトップに my-python というフォルダを作り、その中に test.py という名前でファイルを作成してください。

msg = "Pythonの自動化、最高！"
print(msg)

実行方法（ここでもミスが多い！）

  1. ターミナル（WindowsならコマンドプロンプトやPowerShell）を開きます。
  2. cd デスクトップ/my-python と入力して、ファイルがある場所へ移動します。
  3. ここがポイント： python test.py と入力してEnterキー！
ヒント：もし「'python' は、コマンドとして認識されていません」と出たら、手順1の「PATH」のチェック忘れです。

4. 初心者が絶対にはまる「ミスの要因」集

  • 全角スペースの混入: コードの途中に全角スペースが入っていると動かなくなります。必ず「半角」で書きましょう。
  • ファイル名のミス: test.py.txt のように、後ろに .txt が隠れていませんか？ 拡張子が表示される設定を確認しましょう。
  • python か python3 か: Macをお使いの方は、python ではなく python3 と打たないと動かない場合があります。
まとめ：まずはこの「環境構築」さえクリアすれば、あとは楽しい自動化の世界が待っています！
