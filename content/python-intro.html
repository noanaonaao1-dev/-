Step 1: Proper Installation

Python is the foundation of our automation tools. But many beginners fail at the very first step.

Crucial: Go to python.org and download the "Windows Installer (64-bit)" or the Mac equivalent.

The #1 Mistake: Forgotten PATH

When you run the installer, look at the very bottom of the first window. You MUST check the box that says "Add Python to PATH".

Why? Without this, your computer won't recognize the python command, and you'll get an error like "'python' is not recognized as an internal or external command".

Step 2: Choosing your Editor

Don't use Notepad! Use Visual Studio Code (VS Code).

  • Install VS Code from here.
  • Search for the "Python" extension by Microsoft and install it.

Step 3: Your First Code

Create a folder named python-test and create a file inside called app.py.

name = "Jules"
print(f"Hello, {name}! Automation is fun.")

How to Run (The Safe Way)

  1. Open your terminal or command prompt.
  2. Type python app.py and press Enter.
  3. If that doesn't work, try python3 app.py.

Common Errors and Solutions

  • SyntaxError: Usually a typo or a missing quote.
  • IndentationError: Python is strict about spaces! Make sure your code is aligned correctly.
  • ModuleNotFoundError: You haven't installed a library yet. Use pip install library-name.

「Pythonを始めてみたけど、最初の1歩で動かない...」そんな経験をしたくない人のための、超・親切ガイドです。

1. Pythonのインストール（最大の難所）

まず公式サイト python.org から最新版をダウンロードします。

⚠【最重要】絶対に忘れてはいけないチェック

インストーラーを起動した直後の画面一番下に、「Add Python to PATH」というチェックボックスがあります。

これをチェックしないと、この後の手順が全てエラーになります。

もし忘れてインストールしてしまった場合は、一度アンインストールしてやり直すのが一番確実で早いです。

2. おすすめの「道具箱」：VS Code

メモ帳でプログラムを書いてはいけません。プロも使う Visual Studio Code (VS Code) を使いましょう。

  • VS Code公式サイトからインストール。
  • 左側のアイコンから「Python」と検索し、Microsoft製の拡張機能をインストール。

3. 最初のプログラムを動かす

パソコンのデスクトップに my-python というフォルダを作り、その中に test.py という名前でファイルを作成してください。

msg = "Pythonの自動化、最高！"
print(msg)

実行方法（ここでもミスが多い！）

  1. ターミナル（WindowsならコマンドプロンプトやPowerShell）を開きます。
  2. cd デスクトップ/my-python と入力して、ファイルがある場所へ移動します。
  3. ここがポイント： python test.py と入力してEnterキー！
ヒント： もし「'python' は、コマンドとして認識されていません」と出たら、手順1の「PATH」のチェック忘れです。

4. 初心者が絶対にはまる「ミスの要因」集

● 全角スペースの混入
コードの途中に全角スペースが入っていると動かなくなります。必ず「半角」で書きましょう。
● ファイル名のミス
test.py.txt のように、後ろに .txt が隠れていませんか？ 拡張子が表示される設定を確認しましょう。
● python か python3 か
Macをお使いの方は、python ではなく python3 と打たないと動かない場合があります。

まとめ

まずはこの「環境構築」さえクリアすれば、あとは楽しい自動化の世界が待っています！
